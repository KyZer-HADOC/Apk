# YT Downloader (Android)

Paste (or Share from the YouTube app) a link, pick a quality, and it downloads to your Downloads folder.
Built with NewPipeExtractor. Every push to `main` builds the APK on GitHub Actions
(Actions -> latest run -> Artifacts -> yt-downloader-debug-apk).

Only download content you own or have the right to save; downloading may violate YouTube's Terms of Service.
